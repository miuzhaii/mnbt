# MN宝塔 (MN BaoTa)

MN宝塔是一个基于PHP/MySQL的虚拟主机管理系统，集成了宝塔面板API，提供完整的虚拟主机管理解决方案。

## 功能特性

### 核心功能
- **虚拟主机管理**：支持创建、暂停、删除虚拟主机
- **资源配额控制**：网页空间、数据库空间、流量限制
- **多用户系统**：管理员和用户分级管理
- **宝塔面板集成**：通过API与宝塔面板无缝对接

### 用户功能
- **文件管理**：基于Web的文件管理器，支持上传、下载、编辑、权限设置
- **域名管理**：支持绑定、修改、删除域名，包括中文域名支持
- **SSL证书**：Let's Encrypt自动申请和管理SSL证书
- **数据库管理**：MySQL数据库创建、备份、恢复
- **PHP版本切换**：支持多PHP版本切换
- **伪静态规则**：支持各种程序的伪静态规则配置
- **运行目录设置**：支持设置网站运行目录

### 管理员功能
- **主机管理**：批量管理虚拟主机，支持开通、暂停、删除
- **用户管理**：用户账户管理，密码加密存储
- **域名管理**：二级域名管理和售卖
- **一键部署**：预置常用程序的一键部署模板
- **系统监控**：实时监控主机资源使用情况
- **邮件通知**：配额超限邮件提醒

### API功能
- **RESTful API**：提供完整的API接口
- **自动化部署**：支持API开通主机和一键部署
- **第三方集成**：支持与其他系统集成

## 技术架构

- **后端**：PHP 7.0+
- **数据库**：MySQL 5.6+ / SQLite
- **前端**：Bootstrap + jQuery
- **文件管理**：AmFTP文件管理器
- **代码编辑**：CodeMirror代码编辑器

## 安全特性

- **密码加密**：管理员、用户、数据库密码均采用加密存储
- **权限控制**：严格的用户权限分离
- **安全防护**：SQL注入、XSS攻击防护
- **文件保护**：禁止操作关键配置文件

## 安装要求

- PHP 7.0+
- MySQL 5.6+ 或 SQLite
- 宝塔面板 6.0+
- curl扩展
- mysqli扩展

## 快速开始

1. 上传文件到Web目录
2. 访问install目录进行安装
3. 配置宝塔面板API连接
4. 创建管理员账户
5. 开始使用
