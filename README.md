## 📖 项目简介

MN宝塔是一个基于 PHP/MySQL 开发的虚拟主机管理系统，通过深度集成宝塔面板 API，为虚拟主机服务商和个人站长提供完整的主机管理解决方案。系统采用现代化架构设计，具有响应速度快、功能丰富、易于部署的特点。

### ✨ 核心优势

- 🔌 **深度集成** - 与宝塔面板无缝对接，充分利用宝塔强大的服务器管理能力
- 🎯 **用户友好** - 直观的管理界面，简化虚拟主机的日常运维工作
- 🔒 **安全可靠** - 多层密码加密、权限分离、安全防护机制
- 🚀 **高性能** - 优化的代码结构，快速响应用户请求
- 🔧 **易于扩展** - 模块化设计，支持自定义功能扩展

## 🔐 安全特性

- 🔑 **多重加密** - 管理员、用户、数据库密码均采用加密存储
- 🛡️ **权限控制** - 严格的用户权限分离机制
- 🚫 **安全防护** - SQL注入、XSS攻击等常见攻击防护
- 🔒 **文件保护** - 禁止通过文件管理器操作关键配置文件
- 🔐 **传输加密** - 登录密码采用SHA256哈希传输，防止明文泄露

---

## 📋 环境要求

- **PHP版本**: 7.0 或更高
- **数据库**: MySQL 5.6+ 或 SQLite
- **Web服务器**: Nginx / Apache
- **宝塔面板**: 6.0 或更高版本
- **PHP扩展**: curl, mysqli, mbstring, json, zip

## 🚀 快速开始

### 方法一：自动安装（推荐）

```bash
# 1. 克隆项目到Web目录
git clone https://github.com/miuzhaii/mnbt.git
cd mnbt

# 2. 设置目录权限
chmod -R 755 .
chmod -R 777 filecx
chmod -R 777 imsetes/upload_logo

# 3. 访问网站自动跳转安装
浏览器访问：http://yourdomain.com/
系统会自动检测并跳转到安装向导
```

### 安装向导功能

安装向导会引导您完成以下步骤：

1. ✅ **环境检测** - 自动检查PHP版本和必需扩展
2. ✅ **数据库配置** - 填写数据库连接信息
3. ✅ **自动部署** - 自动生成配置文件（config.php、MPHX/SQ.php）
4. ✅ **数据库初始化** - 自动导入数据表结构
5. ✅ **管理员设置** - 默认账号 `admin` / 密码 `123456`

> ⚠️ **安全提示**: 安装完成后请立即修改默认管理员密码！

### 方法二：手动配置

如需手动配置，请参考 [完整安装指南](INSTALL.md)

## 📅 更新日志

### 🎉 2025-01-12 - 安全性与稳定性重大更新

#### 🐛 修复的问题

1. **PHP语法错误修复**
   - ✅ 修复了 `/user/ajax.php:295` 的 orphaned else 语法错误
   - ✅ 解决了网站无法加载的问题

2. **缺失功能恢复**
   - ✅ 恢复了 `indexconf` 操作（控制面板配置获取）
   - ✅ 恢复了 `mailbd` 操作（邮箱绑定）
   - ✅ 恢复了其他被截断的操作功能

3. **管理面板密码显示优化**
   - ✅ 修复了管理面板显示加密密码（MNENC:...）的问题
   - ✅ 实现了密码隐藏/显示切换功能（眼睛图标）
   - ✅ 编辑窗口正确显示解密后的密码

4. **登录验证修复**
   - ✅ 修复了密码加密存储导致的登录失败问题
   - ✅ 使用 `mn_format_host_row()` 自动解密密码进行验证

5. **配置加载稳定性改进**
   - ✅ 修复了流量数据类型错误（false值）导致的加载卡住问题
   - ✅ 添加了数据类型验证确保流量值为数字
   - ✅ 添加了完整的错误处理机制

6. **流量统计修复**
   - ✅ 修复了流量刷新累加错误（应该是重新计算而非累加）
   - ✅ 修复了未定义变量导致的错误
   - ✅ 正确区分CDN产品和普通主机产品的流量统计

7. **安全性增强**
   - ✅ 实现了SHA256密码哈希传输（防止明文传输）
   - ✅ 密码哈希算法：`SHA256(密码 + 用户名)`
   - ✅ 使用CryptoJS 4.1.1库进行客户端哈希

8. **错误处理全面升级**
   - ✅ 为配置加载添加了try-catch和fail()回调
   - ✅ 为流量刷新添加了错误处理和网络异常捕获
   - ✅ 为伪静态配置添加了完整的错误提示和加载指示器控制
   - ✅ 所有AJAX请求都确保在成功/失败时关闭加载指示器

#### 🔧 技术改进

- **加密系统** - 保持使用 `mn_encrypt()`/`mn_decrypt()` 可逆加密用于FTP/SQL同步
- **哈希传输** - 登录验证采用SHA256哈希，密码不再明文传输
- **数据验证** - 添加了流量、空间等关键数据的类型验证
- **错误日志** - 所有错误都记录到浏览器控制台便于调试

#### 📁 涉及文件

- `/user/ajax.php` - 核心API后端逻辑修复
- `/user/login.php` - 登录页面SHA256哈希实现
- `/user/sy.php` - 控制面板首页错误处理
- `/user/set.php` - 伪静态配置错误处理
- `/admin/ajax.php` - 管理面板密码解密
- `/admin/list.php` - 管理面板密码显示优化
