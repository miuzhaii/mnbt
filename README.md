# MN宝塔 (MN BaoTa)

MN宝塔是一个基于PHP/MySQL的虚拟主机管理系统，集成了宝塔面板API，提供完整的虚拟主机管理解决方案。

## 功能特性

### 核心功能
- **虚拟主机管理**：支持创建、暂停、删除虚拟主机
- **资源配额控制**：网页空间、数据库空间、流量限制
- **多用户系统**：管理员和用户分级管理
- **宝塔面板集成**：通过API与宝塔面板无缝对接

### 用户功能
- **文件管理**：基于Web的文件管理器，支持上传、下载、编辑、权限设置
- **域名管理**：支持绑定、修改、删除域名，包括中文域名支持
- **SSL证书**：Let's Encrypt自动申请和管理SSL证书
- **数据库管理**：MySQL数据库创建、备份、恢复
- **PHP版本切换**：支持多PHP版本切换
- **伪静态规则**：支持各种程序的伪静态规则配置
- **运行目录设置**：支持设置网站运行目录

### 管理员功能
- **主机管理**：批量管理虚拟主机，支持开通、暂停、删除
- **用户管理**：用户账户管理，密码加密存储
- **域名管理**：二级域名管理和售卖
- **一键部署**：预置常用程序的一键部署模板
- **系统监控**：实时监控主机资源使用情况
- **邮件通知**：配额超限邮件提醒

### API功能
- **RESTful API**：提供完整的API接口
- **自动化部署**：支持API开通主机和一键部署
- **第三方集成**：支持与其他系统集成

## 技术架构

- **后端**：PHP 7.0+
- **数据库**：MySQL 5.6+ / SQLite
- **前端**：Bootstrap + jQuery
- **文件管理**：AmFTP文件管理器
- **代码编辑**：CodeMirror代码编辑器

## 安全特性

- **密码加密**：管理员、用户、数据库密码均采用加密存储
- **权限控制**：严格的用户权限分离
- **安全防护**：SQL注入、XSS攻击防护
- **文件保护**：禁止操作关键配置文件

## 安装要求

- PHP 7.0+
- MySQL 5.6+ 或 SQLite
- 宝塔面板 6.0+
- curl扩展
- mysqli扩展

## 快速开始

1. 上传文件到Web目录
2. 访问install目录进行安装
3. 配置宝塔面板API连接
4. 创建管理员账户
5. 开始使用

## 快速部署

### 从GitHub克隆

```bash
git clone https://github.com/your-username/mnbt.git
cd mnbt
cp config.sample.php config.php
cp MPHX/SQ.sample.php MPHX/SQ.php
# 编辑config.php配置数据库信息
# 导入database.sql到数据库
```

详细安装步骤请查看 [安装指南](INSTALL.md)

### 准备发布到GitHub

如果你想将已安装的系统发布到GitHub，请运行清理脚本：

```bash
bash cleanup_for_git.sh
```

该脚本会自动：
- 备份并清理敏感配置（数据库密码、授权码）
- 清理用户上传的文件和临时文件
- 创建配置文件模板
- 保留必要的目录结构

## 更新日志

### 2025-01-12 安全性与稳定性重大更新

#### 修复的问题

1. **PHP语法错误修复**
   - 修复了 `/user/ajax.php` 第295行的orphaned else语法错误
   - 解决了网站无法加载的问题

2. **缺失功能恢复**
   - 恢复了 `indexconf` 操作（控制面板配置获取）
   - 恢复了 `mailbd` 操作（邮箱绑定）
   - 恢复了其他被截断的操作功能

3. **管理面板密码显示优化**
   - 修复了管理面板显示加密密码（MNENC:...）的问题
   - 实现了密码隐藏/显示切换功能（眼睛图标）
   - 编辑窗口正确显示解密后的密码

4. **登录验证修复**
   - 修复了密码加密存储导致的登录失败问题
   - 使用 `mn_format_host_row()` 自动解密密码进行验证

5. **配置加载稳定性改进**
   - 修复了流量数据类型错误（false值）导致的加载卡住问题
   - 添加了数据类型验证确保流量值为数字
   - 添加了完整的错误处理机制

6. **流量统计修复**
   - 修复了流量刷新累加错误（应该是重新计算而非累加）
   - 修复了未定义变量导致的错误
   - 正确区分CDN产品和普通主机产品的流量统计

7. **安全性增强**
   - 实现了SHA256密码哈希传输（防止明文传输）
   - 密码哈希算法：`SHA256(密码 + 用户名)`
   - 使用CryptoJS 4.1.1库进行客户端哈希

8. **错误处理全面升级**
   - 为配置加载添加了try-catch和fail()回调
   - 为流量刷新添加了错误处理和网络异常捕获
   - 为伪静态配置添加了完整的错误提示和加载指示器控制
   - 所有AJAX请求都确保在成功/失败时关闭加载指示器

#### 技术改进

- **加密系统**：保持使用 `mn_encrypt()`/`mn_decrypt()` 可逆加密用于FTP/SQL同步
- **哈希传输**：登录验证采用SHA256哈希，密码不再明文传输
- **数据验证**：添加了流量、空间等关键数据的类型验证
- **错误日志**：所有错误都记录到浏览器控制台便于调试

#### 涉及文件

- `/user/ajax.php` - 核心API后端逻辑修复
- `/user/login.php` - 登录页面SHA256哈希实现
- `/user/sy.php` - 控制面板首页错误处理
- `/user/set.php` - 伪静态配置错误处理
- `/admin/ajax.php` - 管理面板密码解密
- `/admin/list.php` - 管理面板密码显示优化
